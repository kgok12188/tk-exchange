# 市价单与交易对资产语义（BTC_USDT 示例）

本文档说明 **现货撮合协议** 中交易对、base/quote、市价 IOC 与 **业务侧锁仓** 的对应关系；**撮合引擎不维护用户余额**，锁仓与解冻由 **trading-server / 账户服务** 实现。

## 1. 交易对符号

以 **BTC_USDT** 为例：

| 名称 | 资产 | 说明 |
|------|------|------|
| **base（标的）** | BTC | 成交量、挂单量的单位 |
| **quote（计价）** | USDT | 成交价 × 成交量 = 成交额（USDT） |

协议字段 `OrderPayload.volume`、成交 `TradeOrder.volume` 在引擎侧均表示 **base 数量（BTC）**。  
`OrderPayload.amount` 表示 **quote（USDT）**：市价买单上为 **最多成交金额**；市价卖单上可选为 **累计成交额上限**。

## 2. 市价单（`priceType = MARKET`，IOC）

- 语义为 **IOC**：只与对手盘撮合，**不入簿**；未成交部分以 `PART_CANCEL` 等结束（见 `MarketOrderMatcher`）。
- **撮合规则摘要**：
  - **BUY**：**`amount` 必传**（最多花多少 USDT）；**`volume` 可选**，`>0` 时同时限制最多买到多少 BTC，`null/0` 表示仅受 `amount` 约束。
  - **SELL**：**`volume` 必传**（最多卖多少 BTC）；**`amount` 可选**，`>0` 时限制 **累计成交额** Σ(价×量) 不超过该值，`null/0` 表示不限制成交额。
- 每一笔成交在档位价格上计算 `fillBase`，同时扣减剩余 quote 预算与（若启用）base/成交额上限。

### 2.0 引擎内 `BookOrder`（市价）：`volume` / `remainingVolume` 与 `amount` / `remainingAmount`

撮合内存单 **非协议 DTO**，但与 `OrderPayload` 对齐命名：

| 字段 | 含义 |
|------|------|
| `volume` | 原始 **base** 数量：市价卖为待卖 base；市价买若有 `volume>0` 上限则为该上限初值，无上限时为 0。 |
| `remainingVolume` | 剩余 **base**：市价卖递减；市价买仅在设有 base 上限时递减。 |
| `amount` | 原始 **quote（计价货币）**：市价买为最多花费；市价卖若设累计成交额上限则为该上限初值；未设上限时可为 null。 |
| `remainingAmount` | 剩余可成交 **quote**：市价买为剩余预算；市价卖为剩余成交额上限；无 quote 约束时为 null。 |

限价单通常仅使用 `volume` / `remainingVolume` 与 `price`；`amount` / `remainingAmount` 为 null。

### 2.1 `MarketConfig.minTradableQuoteNotional`（业务完单阈值，quote）

- **字段**：`minTradableQuoteNotional`（BigDecimal，单位 = 该交易对 **quote** 资产，如 USDT）。
- **比较**：当市价单在 **quote 维度**度量的「仍可继续成交的剩余名义」**严格小于**（**`<`**）该值时，**产品/展示层**可视为 **完单 / 不可再成交**（与撮合结果中可能仍为 `PART_CANCEL` 且带微量剩余 区分）。
- **未配置**：`null` 或 ≤0 表示 **不启用** 该业务规则。
- **与撮合引擎**：`match-engine` 在 `MarketOrderMatcher` / `MarketRules` 中实现：当剩余 quote 名义 **&lt;** `minTradableQuoteNotional`（且配置为正）时**停止继续撮合**；终态为 `COMPLETED`（自然耗尽或买单无 base 上限仅 quote 粉尘）或 `PART_CANCEL`（仍有 base 等可报告剩余）。`trading-server` / 前端可在此基础上做展示与解冻。

### 2.2 业务侧锁仓（非 match-engine）

| side | 建议锁定资产 | 与字段关系 |
|------|--------------|------------|
| **BUY** | USDT（quote） | 与 **`amount`** 一致（或含滑点安全边际） |
| **SELL** | BTC（base） | 与 **`volume`** 一致 |

### 2.3 `PART_CANCEL` 与 `leaveVolume`

- **卖单**：`leaveVolume` 为未卖完的 **base**。
- **买单**：若仅按 `amount` 约束（未传 `volume` 上限），`leaveVolume` 在 base 维度可为 **0**（剩余未花 quote 由账户侧处理）；若传了 `volume` 上限，则为未买满的 **base**。

## 3. 限价单（`priceType = LIMIT`）

- `price` 为限价；`volume` 为 base 数量；也可用 `amount` + `price` 折算为 base（见 `OrderBook#effectiveVolume`）。

## 4. 与 match-engine 的边界

- 引擎按上述规则消费 `OrderPayload`，产出 `TradeOrder` / `FinishOrder`。
- **谁锁哪种币、锁多少** 不在 match-engine 内完成，须与 base/quote 语义一致。

## 5. 相关代码入口

- `trading-protocol`：`OrderPayload`  
- `match-engine`：`OrderBook#pushMarketOrder`、`MarketOrderMatcher`（预算与 IOC）
